# Executed exploratory validation, 28 October 2026

These are unchanged summary records from the manuscript validation package, not new application runs. They describe 480 constructed revisions and 3,840 method rows, 36 authored BIM-Edit pairs from five building identifiers, and 20 topology controls. The source-model feature sets come from two example projects; repeated seeds and edit pairs are not independent projects.

The external labels are partial common-identifier references, not independently reviewed physical-asset labels. Overall recall must be read beside the changed-target audit: the review matcher recovered six of twelve updated targets. Container identifiers remain features when object identifiers and Tags are masked. See external_repository.json for the pinned BIM-Edit source and raw_sources.json for model provenance.

The review-v2 application adapter adds a retained-GlobalId stage, geometry-free exact matching and human approval safeguards. The saved validation measured identifier-masked matching; its scores must not be advertised as measured accuracy of this extended application workflow.

This folder is a summary and provenance release. The complete IT2_validation_code_and_results.zip supplied with the manuscript contains per-case results, prediction/reference pairs, cached geometry derivatives, code, source snapshot and package hashes for reproduction. The repository summaries alone are not the complete reproduction package. The original study artifacts remain separately protected by docs/paper_snapshot_sha256.json.
