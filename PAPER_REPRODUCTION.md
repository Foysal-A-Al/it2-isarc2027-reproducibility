# Reproducing the ISARC paper evidence

This document maps the **seven-page IT2 ISARC manuscript** ("Verifying Cross-Revision Referential Integrity in IFC Models: An Empirical Failure Analysis of Asset Correspondence and Network Topology") to the actual repository evidence. It does not claim that every result has been independently rerun from raw IFCs.

> **Important:** The repository also preserves a broader, older IT2 project. Its historical figure numbers in [REPRODUCIBILITY.md](REPRODUCIBILITY.md) and [figures/](figures/) are **not** the numbering of the current ISARC manuscript. The manuscript includes **Table 1–6 and Figure 1–2**.

### Reading the numbers

- **Table 3:** The 36 pairs are **12 creation + 12 update + 12 deletion** cases involving five source-building identifiers, not 36 independent buildings. **97.90%** is a macro-average across pairs; **6/12** scores the labelled update targets. The **Created** and **Deleted** counts in the published table are false links/carry-forwards, **not** correctly recovered creations/deletions.
- **Table 4:** The experiment preserves Tags, introduces small placement changes and either keeps or regenerates GlobalIds. It is a controlled ID-dependence check, **not** a general benchmark of matching accuracy or a BIMdiff execution.
- **Table 5:** The model-specific comparisons deliberately include decoys and show different outcomes in Plumbing versus MEP. They do not prove one method is universally better.
- **Table 6:** Values are means of 60 model-seed runs from **three fixed models**, not 60 independent buildings. In the saved results, review-aware precision for coincident decoys is **99.749450545%**; rounding directly to one decimal gives **99.7%** (the manuscript may display 99.8%). State the display convention or correct the manuscript entry.
- **Figure 2:** The series called **placement** is placement-origin assignment from [it2/matching.py](it2/matching.py), not the centre-plus-dimensions geometry stage.
- **Rejection policy:** The archived BIM-Edit validation gives the same outcomes for a zero-margin and a 0.03 m review-aware variant; the latter's separate benefit is **not** established by that subset.

## Reproduction routes

**1. Saved-feature checks (completed previously).** Using the environment in [environment.yml](environment.yml):

~~~powershell
python scripts/reproduce_study.py --mode saved-features
~~~

This creates an external workspace and compares regenerated identity, sensitivity and round-trip summary JSON to the saved snapshots. It **does not** rerun Tables 3–6 or the independent topology control.

**2. Public IFC extraction and topology (requires downloads).**

~~~powershell
python data/download.py
python scripts/reproduce_study.py --mode raw-ifc
~~~

Raw-IFC mode also runs file-level round trips, but does not cover all external comparator cases. Read [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for source and environment caveats. Do not overwrite historical saved artifacts merely to make a rerun agree.

**3. Figure 2 and independent negative control (write to a NEW output directory).**

~~~powershell
python scripts/plot_isarc_identity.py ./local-audit-output
python scripts/93_topology_negative_control.py data/ifc/Duplex_Plumbing_20121113.ifc ./local-audit-output
~~~

The output directory should be kept outside the repository for a protected audit. The published [audit evidence](audit/2026-11-13/) is a snapshot of a prior independent run; new run outputs may be placed elsewhere.

**4. Optional direct comparators and stress scripts.** The following are **not part of the standard reproduction harness**:

~~~powershell
python scripts/90_comparator_full.py
python scripts/91_contemporary_comparison.py --models Duplex_Plumbing --seeds 1 --start 3000
python scripts/92_ambiguity_comparison.py --models Duplex_Plumbing --seeds 3 --start 4000
python scripts/94_ifcdiff_direct_check.py
~~~

These commands require the actual raw IFCs and, for contemporary tools, compatible installations of **bimdelta-core 0.9.0** and **ifcdiff 0.9.0**. Those are optional comparator dependencies **not installed by environment.yml**; see [comparator environment record](audit/2026-11-13/comparator-environment.txt). Check the relevant script's arguments before running, particularly the direct IfcDiff script. The stress scripts may write into results/; for an integrity-preserving rerun, execute them in a **separate working copy** rather than the archived repository.

## Evidence and integrity boundaries

1. Saved JSON agreement is **not** equivalent to complete raw IFC re-execution.
2. The BIM-Edit raw files are provided by the upstream benchmark and are **not redistributed** in this repository. Its source selection, exclusions and truth definition are recorded in the [validation archive](research/validation-2026-10-28/).
3. For controlled IFCs, the ground truth is known by construction; it is **not** independently adjudicated physical identity.
4. Graph results concern **explicit, undirected IFC port connectivity**, excluding missing or ambiguous ownership. A changed relation need not be an engineering error; no live sensor-to-asset link was verified.
5. Figure and historical script numbering in old research documents may differ from the manuscript; use the table above as the **paper-specific** index.
6. The status of previous independent checks is documented in [AUDIT_STATUS.md](audit/2026-11-13/AUDIT_STATUS.md). That audit note records open comparator cases and should not be interpreted as certification of every experiment.
